隐私政策

生效日期：2026年10月16日
运营者：蔡沂岑

政策版本：2026-10-16

一、我们处理的信息

轻衡用于记录体重、饮食、活动热量、排便情况和营养数据。用户主动填写的身体资料、健康记录和应用设置默认保存在当前设备中。轻衡无需注册账号即可使用，运营者不会据此建立线上用户档案。

二、AI 识别

AI 是可选功能。用户可以自行填写第三方 AI 服务的接口地址、模型标识和 API Key。只有用户主动点击照片、相册或文字识别并确认发送时，所选图片、文字以及完成识别所需的提示信息才会直接发送到用户选择的 AI 服务商。轻衡不会通过运营者服务器中转 AI 识别内容。

API Key 保存在 Android 系统安全存储中，不进入轻衡 JSON 备份。AI 返回内容会先显示为待确认草稿，用户确认后才写入本机记录。

三、私人同步

私人同步默认关闭。用户主动启用后，轻衡会连接用户配置的 HTTPS 同步服务，使用只读令牌获取等待导入的记录事件。只读令牌保存在 Android 系统安全存储中，不进入 JSON 备份。

如用户使用运营者提供的 Cloudflare Workers/KV 私人同步服务，事件将保留至用户申请删除或相关服务终止。用户可通过本政策所列邮箱申请删除云端事件。

四、权限使用

  • 网络权限：用于用户主动调用 AI 服务、测试接口和使用已配置的私人同步。
  • 麦克风权限：仅在用户点击语音录入时申请，用于调用 Android 系统语音识别；轻衡不保存原始录音。
  • 照片与相机：仅在用户主动拍照或选择图片时，通过 Android 系统界面取得用户选择的单张图片；轻衡不扫描整个相册。

拒绝麦克风、照片或相机相关授权，不影响手工记录、本地食品库、体重趋势和备份等功能。

五、第三方服务与组件

轻衡使用 Capacitor Core、Capacitor App、Capacitor Camera 和 AndroidX 提供跨平台运行、系统交互、相机选图与兼容能力。这些运行组件不用于建立轻衡用户档案。

用户选择火山引擎/豆包或其他兼容 AI 服务时，用户主动发送的信息同时受对应服务商隐私政策约束。用户使用基于 Cloudflare Workers/KV 的私人同步时，网络请求和同步事件会由 Cloudflare 基础设施处理。

六、保存、导出与删除

本机记录会保留到用户主动清空应用数据、卸载应用，或在“我的 → 隐私与数据”中清空全部本机数据。用户可以随时导出 JSON 备份。

API Key 和同步只读令牌不包含在备份中，可分别在 AI 设置和同步设置中删除或停用。用户也可以通过联系邮箱申请删除由运营者提供的私人同步服务中的云端事件。

七、未成年人

轻衡主要面向具备独立健康管理能力的成年人。未成年人应在监护人指导下使用，不应将轻衡的估算结果用于自行诊断或治疗。

八、健康信息说明

轻衡提供的是一般体重、饮食和营养记录及估算，不构成医学诊断、治疗建议或医疗器械功能。食材、烹饪方式、图片识别和用户输入均可能带来误差；存在疾病、特殊营养需求或异常症状时，应咨询医生或营养专业人员。

九、用户权利

用户可以在应用内查看、更正、导出或删除本机记录，可以撤回非必要权限，也可以在“我的 → 隐私与数据”中撤回对本政策的同意。撤回后，轻衡会停止 AI 和私人同步等数据处理，直到用户再次同意。

用户可通过 caiyicen54@gmail.com 咨询隐私问题、提出投诉或申请删除云端事件。运营者将在适用法律和应用市场要求的期限内处理。

十、政策更新

功能、第三方服务或数据处理方式发生重大变化时，运营者将更新本政策版本，并在应用内再次提示用户阅读和同意。
